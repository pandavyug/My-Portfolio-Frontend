# Yug Pandav Portfolio

A responsive personal portfolio built with React, React Router, Tailwind CSS, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Personalization

Update `src/data/siteData.js` for:
- Email
- GitHub / Instagram / LinkedIn / Facebook URLs
- Project links and descriptions
- Project technologies

Replace:
- `public/profile.jpg`
- `public/resume.pdf`
- `public/projects/*.jpg`

The contact form is frontend-only and displays a success message after validation. Connect it to a backend or form service later if you want real message delivery.
